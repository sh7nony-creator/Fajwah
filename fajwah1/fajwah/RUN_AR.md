# تشغيل فَجْوَة

## المعاينة المحلية

من مجلد المشروع:

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py --global.developmentMode false --server.address 127.0.0.1 --server.port 8501
```

ثم افتح http://127.0.0.1:8501.

في هذا المجلد داخل جلسة Codex يمكن تشغيل `Start-Fajwah.ps1` لاستخدام المكتبات المثبتة محليًا في مساحة العمل.

## التصميم والبيانات

الواجهة مبنية على إطار Default الفاتح (98469:145264) في ملف Snow Dashboard UI Kit الذي تم توفيره، مع عكس الاتجاه للعربية. تخطيط البطاقات وألوانها وحوافها وأبعاد الأعمدة مستمدة من Figma. تعرض الرسومات قيم فَجْوَة الفعلية، وتعرض لوحة الرؤى معلومات المنطقة بدل إشعارات وأسماء المثال. الخريطة والجداول والرتب الأصلية محفوظة أسفل الملخص.

`DATA_INTEGRITY.json` يوثق التطابق الكامل لملفات البيانات ومحرك الحساب مع الأرشيف الأصلي. تم الاحتفاظ بالمصادر وحدود التحليل الفعلية في قسم المنهجية، وبالتحقق من البيانات ومعالجة الأخطاء.

## الاختبارات

```powershell
python -m unittest discover -s tests -v
```

تحتاج اختبارات التفاعل إلى اتصالات loopback المحلية وإلى مهلة تشغيل تبلغ 30 ثانية على الأجهزة البطيئة. لم يتم النشر أو تعديل النسخة الإنتاجية.
