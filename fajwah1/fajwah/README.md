# فَجْوَة — الصفحة الإقليمية

طبقة بيانات للنتائج المعتمدة وصفحة إقليمية تفاعلية وصفحة مؤشرات وطنية بالعربية باستخدام Streamlit وPlotly. صفحة المنهجية ما زالت موضعًا محجوزًا.

## المؤشرات الوطنية

من القائمة الجانبية اختر «المؤشرات الوطنية»، ثم أحد الأقسام السبعة ومرشحات الجنس والجنسية المتاحة. السكن للسعوديين فقط وبوحدة أفراد، والمعروض حيازة المسكن دون نوع المبنى. باقي الأقسام نسب منشورة، مع أبعاد الاندماج الرقمي مستقلة وغير قابلة للجمع.

src/national_data.py يقرأ الجداول الوطنية من مصدرها مباشرة، ويتحقق من الرؤوس والمواقع والوحدات والقيم دون تعويض المفقود بصفر أو احتساب متوسطات بين الفئات. src/national_views.py ينشئ الرسوم والتفسيرات الوصفية دون ربط بالبيانات الإقليمية أو افتراض حجم عينة موحد. راجع PHASE4_REPORT.md وسجل PHASE4_TEST_OUTPUT.txt للتفاصيل والاختبارات والقيود. لا توجد اعتماديات جديدة.

## الصفحة الإقليمية

خريطة Plotly Choroplethmap / MapLibre من ملف GeoJSON المحلي، بخلفية فاتحة محلية لا تتطلب مفتاح خرائط أو تحميل بلاطات. النقر يرسل location (رمز ISO) عبر on_select إلى callback يحدث اختيار المنطقة قبل إعادة بناء الصفحة. القائمة مصدر بديل للاختيار، ولا تتغير المنطقة عند تبديل المؤشر. hover يعرض القيم، والإطار الداكن يوضح الاختيار. تدعم الخريطة السحب والتكبير بالإيماءات؛ عجلة التكبير معطلة.

أعيد تنسيق الصفحة الإقليمية وفق لوحة SnowUI الفاتحة من ByeWind، مع تنقل جانبي عربي على سطح المكتب، وتنقل علوي على الهاتف وخمس بطاقات KPI باستيل ولوحة رؤى للمنطقة. بقيت الخريطة والبيانات والرتب والتفاعلات من نفس الطبقة السابقة. src/regional_ui.py مسؤول عن المظهر، ولم يتغير الثيم العام للصفحة الوطنية. راجع SNOWUI_REPORT.md وSNOWUI_TEST_OUTPUT.txt لأحدث مراجعة واختبارات وحدود المطابقة. تقرير REDESIGN_REPORT.md يوثق المظهر الداكن السابق.

مؤشر السكان ومؤشر كبار السن منفصلان في الألوان والبطاقة والرتب والمقارنات والجدول. الافتراضي الآن فجوة الكثافة = المعدل الوطني − كثافة المنطقة؛ الموجب ضعف نسبي، والترتيب تنازلي. تُحسب لكل 100 ألف نسمة، أو لكل 10 آلاف من كبار السن، مع بقاء البسط إجمالي الجهات. يمكن اختيار فرق الجهات العددي المستقل = الفعلي − المرجع، بترتيب Excel التصاعدي الأصلي. هذه مشتقات للعرض في src/presentation.py دون تعديل الحسابات الأصلية.

الأحمر دائمًا أقل من المرجع والبترولي أعلى منه: لذا ينعكس اتجاه التدرج العددي بين نوعي القياس ولا ينعكس معناه التحليلي. التدرج متماثل حول الصفر وثابت لجميع المناطق في القياس نفسه، ويتغير فقط بتغيير المؤشر/نوع القياس. لا تُقارَن شدة اللون بين معياري السكان وكبار السن. القيم مقربة إلى منزلتين للعرض فقط. الجدول يحتفظ بالقيم الكاملة ويتضمن الرتبتين بوحدات واضحة، ويمكن فرزه وتنزيل CSV من شريطه.

الخريطة مكبّرة على سطح المكتب. زر «ملاءمة الخريطة للشاشات الصغيرة» يقلل التكبير لإظهار المملكة في مساحة الهاتف. الإطار الداكن لا يغير ألوان المؤشر. بطاقة التفاصيل تقارن كثافة المنطقة بالمعدل الوطني، والتفسير النصي ينشأ بقواعد Python حتمية دون استدعاء نموذج ذكاء اصطناعي.

RTL عبر CSS داخل Streamlit، مع ترتيب البطاقة أسفل الخريطة في الشاشات الصغيرة. تتطلب الخريطة متصفحًا يدعم WebGL. اختُبرت النقرات فعليًا في المتصفح، وليست نتيجة مفترضة من اختبارات AppTest وحدها.

راجع REVISION_REPORT.md لنتائج أحدث مراجعة، وPHASE3_TEST_REPORT.md لسجل اختبارات المرحلة الثالثة السابق.

## التشغيل

من مجلد `fajwah`، باستخدام Python 3.12:

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m unittest discover -s tests -v
.venv\Scripts\python -m streamlit run app.py
```

`requirements-lock.txt` يسجل الإصدارات التي اختُبرت محليًا؛ يمكن استخدامه بدل requirements.txt لإعادة إنتاج البيئة.

## عقد البيانات

`src.data.load_regional_bundle()` يرجع DataFrame وGeoJSON بعد التحقق؛ يرفع خطأ عند الفشل ولا يصلح البيانات تلقائيًا. يعيد `load_boundaries()` نسخة ذاكرة مضافًا إليها `region_id` و`region_name_ar` و`id`؛ لا يغير هندسة المصدر. ملفات Excel في data/raw نسخ مطابقة بايتًا للأرشيف الأصلي، وبصماتها في data/reference/raw_checksums.json. لا يعاد تشغيل سكربت إنتاج التقارير.

الفجوة العددية المعتمدة في Excel = الفعلي − المتوقع. المتوقع = إجمالي الجهات × حصة المنطقة من السكان أو كبار السن حسب المؤشر. السالب أقل من التوزيع التناسبي. رتبة Excel العددية 1 لأكثر الفجوات سلبية، مع method=min للتعادل. ترتيب الجدول الأساسي حسب السكان لا يمثل ترتيب الفجوة. قاموس METRICS يفصل المؤشرين. الرتبة النسبية المشتقة للواجهة مستقلة عن رتبة Excel كما هو موضح أعلاه.

## الحدود والمصادر

راجع data/reference/SOURCE.md. ربط صريح بالاسم ورمز ISO، دون تخمين تقريبي. حدود geoBoundaries تمثل 2017 وليست إصدارًا سعوديًا رسميًا حديثًا. فحص الهندسة لا يثبت حداثة الحدود أو دقتها القانونية.

## القيود والاختلافات

- السكان 2024 وكبار السن 2025؛ نسبة كبار السن تقريبية. تاريخ لقطة الجهات يحتاج توثيقًا.
- إجمالي الجهات 2645؛ السجل يتضمن جمعيات ومؤسسات ولا يثبت تخصصها في كبار السن أو القدرة التشغيلية أو الاحتياج غير الملبّى.
- رقم التسجيل منفردًا ليس مفتاحًا فريدًا: 258 تكرارًا؛ الزوج (رقم التسجيل، نوع الجهة) فريد. لم تُحذف سجلات أو تتغير الحسابات.
- يتجاهل قارئ سجل الجهات صف عنوان واحدًا وصف تسمية لوحة بلا منطقة، كما يفعل الحساب المعتمد؛ أي منطقة أخرى غير معروفة تفشل التحقق.
- المؤشرات الوطنية داخل ملف كبار السن، لكنها لا تدخل هذه الطبقة الإقليمية. صفحة المؤشرات الوطنية مجرد موضع محجوز؛ تجهيز جداولها خارج نطاق هذه المرحلة.
- لا تعني القيم الموجبة فائض خدمات فعليًا، ولا تعني القيم السالبة عدد الجهات الواجب إنشاؤها.

اختبارات unittest تشمل الربط والمجاميع والمدخلات والتقارير والمعادلات والإشارة والرتب والهندسة والبصمات، إضافة إلى رفض البيانات المعطوبة عمدًا.
